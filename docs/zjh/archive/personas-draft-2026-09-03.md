## 一、老油条 · 阿杰（紧凶）

> §4.7.3 原话：打了二十年的老手。细记牌、2 轮前瞻、读用时；起手紧、拿到货就加压；
> 比牌只挑最弱；升档偷池挑软桌；单挑收口快。破绽：太理性，面对连续加压会规矩地弃，
> 能被反复偷；几乎不闷比，闷牌王能压他。情绪：几乎不上头，被抓一次后两局只用真牌；
> 用时稳定，偶尔演；表情极少。

**起手与看牌。**「起手紧」在这套引擎里不是一条起手表，而是**先看清再决定扔不扔**：
`look.appetite 1.05` 略高于常人，`costWeight 1.00`（常人 0.85）—— 这一口越占身家，
他越要先知道自己拿的是什么。`blindLove 1.15` 把第一轮的免费看戏留给他，
所以他第一轮看牌率 42.1%，比常人的 34.2% 高，但**不是「轮到就看」**（新手那一档）。
`pressureWeight 0.34` 是「读用时」的钱面版本：有人开火了，先把自己的牌看清楚再说。

**线路偏好。**「拿到货就加压」= `价值加压 1.35`；「单挑收口快」= `收口 1.45 / commit 0.70`；
「升档偷池」= `偷池 0.60`，挑软桌那一半在 `allIn.foldEquityWeight 0.95`
（他是四个人里唯一真的去问「这一桌会不会跑」的）。
「面对连续加压会规矩地弃」= `弃 1.75`，四张卡里最高的一条弃牌线；
文档没给数，取的是与人物文字同向的那一侧的上沿（实测 1.30 也能过全部断言，
1.75 把 VPIP 从 53.4% 压到 51.3%，并把两条「同一脚本对老油条不净胜」的对照各多拉开一点）。
「几乎不闷比」= `闷比 0.01`、`闷压 0.18` —— 闷着的两条线他基本不走。
`便宜看戏` 保持常人的 0.10：「不为看结果花钱」已经由 `跟到底看 0.72`、`R4 ×0.5`、
`R33 ×0.3` 三项承担，没有再压一次的理由。

**认知能力。**`rangeFidelity 2`（细记牌）、`lookahead 2`（2 轮前瞻）、
`readsTiming true`（读用时）、`classifyOthers 'fine'`。四张卡里只有他是满配。
其中 `readsTiming` 这一期**没有消费方**，见报告的「待集成」清单。

**认知偏差。**「太理性：几乎没有」逐字落到 `sunkCost 0.10 / gamblersFallacy 0.05 /
overconfidence 0.06`，天性层再压一遍：`R4 ×0.5`（沉没成本）、`R5 ×0.3`（赌徒谬误）、
`R16 ×0.3`（对没看的那手牌不抱幻想）。`R33 ×0.3` 用的是 §4.9.8 的原话
「常人只看这一手……老油条相反」。

**比牌习惯。**「只挑最弱」= `compare.softness 1`（完全按 pWin 挑）+ `grudge 0.15`
（挑的是最弱的，不是最恨的）；「单挑收口快」= `heads 0.46`；
「几乎不闷比」= `blind 0.05`。实测比牌 184 次里 90.8% 挑的是他心里范围最弱的那个，
闷比只占 3.3%（常人 13.3%）。

**梭哈习惯。**原话没写他的梭哈，所以 `initiate / valueFloor / bluff / accept` 四项
**照抄常人**，只改了原话涉及的两项：`blindAccept 0.10`（几乎不闷）和
`foldEquityWeight 0.95`（挑软桌）。**原话没说的不写**是这四张卡共同的规矩。

**情绪曲线。**「几乎不上头」= `tilt.trigger 0.72`、`emotion.tiltTrigger 0.20`、
`R6 ×0.4`，加上 `decay.anger 0.50`（气退得快，常人 0.25）。
实测他只有 **19.4%** 的决策是在上头状态下做的（赌徒 94.1%、常人 69.5%），
平静↔上头的动作位移 26.7%，小于赌徒的 29.4%。
「被抓一次后两局只用真牌」= `R8 ×2.0`（冒进被证伪 → 收紧），是四张卡里最高的。
「不记仇」的钱面：`decay.revenge 0.45`、`compare.grudge 0.15`。

**用时与表演。**「用时稳定」= `tempo.noise 0.03`、`leak 0`（用时不泄露牌力）；
「偶尔演」= `theatre 0.18`。实测均值 397ms、p90 479ms，
p90/均值 = 1.21，常人是 1.49 —— 他的用时分布明显更窄，这就是「稳定」的可测形式。

**表情语言。**「表情极少」= `emotes { rate: 0.05, favourites: ['👍'], cap: 1 }`。

**破绽。**卡里写了两条，每条都带「怎么利用」的剧本（§6.5 要求）：
① 太理性 → 连续加压能把他规矩地逼弃；② 几乎不闷比 → 全程闷着加价到升档能压他。
**两条都只做出了行为侧，没有做成「专属破绽」的钱面对照**，详见报告。
行为侧的证据：他金花以下遇加注 99.3% 弃（279 次），中档牌被连续加压弃 78.4%
（167 次，常人 60.6%）—— 「会规矩地弃」是真的；不成立的是「因此能从他身上偷到钱」：
他在这套注码梯度下弃得**太便宜**（弃在第 1–2 轮，偷池方拿不到足够的底池）。

**对他人的原型归类。**`classifyOthers: 'fine'` —— 细记牌的人给别人贴的标签也细。

## 二、赌徒 · 阿凯（松凶 / 上头王）

> §4.7.3 原话：来找刺激的。粗记牌、0–1 轮前瞻；什么牌都想看看；沉没成本重，
> 投入多了就不弃；喜欢梭哈、喜欢比投入最多的人；连输后起手全开。
> 破绽：上头后小金花也梭，可以拿真牌等他；对偷池免疫（他不弃），但对价值加注全付。
> 情绪：输 8% 触发上头、×0.85 衰减；大赢后更疯；秒出手；表情最多。

**起手与看牌。**「什么牌都想看看」= `look.appetite 1.30`（四张卡最高）、`blindLove 0.45`。
「价钱不是他的输入」= `costWeight 0.35`；「秒出手、别人开火不会让他多想」= `pressureWeight 0.10`。
「喜欢梭哈」还带来 `allInWeight 0.55`：桌上有人梭了，他先看清自己再冲。
实测第一轮看牌率 52.3%，全场最高。

**线路偏好。**「投入多了就不弃」= `跟到底看 1.60 / commit 0.75`；
「他不弃」= `弃 0.30`（全场最低）；
「松凶」= `价值加压 1.25` + `偷池 0.80`；「连输后起手全开」= `养池 1.10`；
「来找刺激的」= `便宜看戏 0.03`、`收口 0.50`（看戏和主动了结都不刺激）。

**认知能力。**`rangeFidelity 1`（粗记牌）、`lookahead 0`（原话给的是 0–1，取下界：
秒出手的人不会算第二轮）、`readsTiming false`、`classifyOthers 'coarse'`。
`s1Prototypes` 整排 ≥ 1.08：什么牌到他手里都显得更值钱一点。

**认知偏差。**「沉没成本重」= `sunkCost 0.85` + `R4 ×2.0`；
「连输后觉得该轮到自己」= `gamblersFallacy 0.55` + `R5 ×2.0`（§4.9.6 逐字）；
`R1 ×1.5`、`R3 ×2.0` 也是 §4.9.6 逐字；`R11 ×0.3` 对应「对价值加注全付」（大注吓不动他）。

**比牌习惯。**「喜欢比投入最多的人」= `compare.softness 0` —— §4.7.2 里 0 就是
「谁投得多挑谁」。其余三项原话未涉及，照抄常人。
**这一条实测没做出来**（他挑的人的下注排名 0.367，与老油条的 0.368 一样），
见报告的异议第 1 条。

**梭哈习惯。**「喜欢梭哈」= `initiate 0.85`；「上头时小金花也梭」= `valueFloor 0.62`
（评分的中心，不是门槛）+ `probWeightAlpha 0.50`（低概率被放大）；
「他不弃」= `accept 0.35`、`blindAccept 0.60`；
「对偷池免疫」的另一半 = `foldEquityWeight 0.15`（他从不问对面会不会跑）。
实测主动梭 342 次，牌力均值 0.726，其中 57.3% 在顺金以下（老油条 0.768 / 45.7%）。
**这条软范围是两句话相乘的结果**：他 94.1% 的决策都在上头状态下做（老油条 19.4%），
而上头时他梭出去的牌 58.7% 在顺金以下。**同样上头**时他单手牌的梭哈率跟别人差不多
（金花档 5.5%，常人 6.4%）—— 区别不在同一心情下的胆子，而在他一直在那个心情里。

**情绪曲线。**「输 8% 触发上头」= `emotion.tiltTrigger 0.08` 逐字；
「×0.85 衰减」= `emotion.decay 0.85` 逐字；`tilt { trigger 0.35, gain 1.6, recover 5 }`；
「大赢后更疯」= `ease { trigger 0.30, gain 1.5 }`（待接线）+ `R6 ×1.6`
+ `expression.joy { looseness .90, aggression .70, greed .60, showoff .60 }`（真正落地的那一半）；
「气留得久」= `decay.anger 0.15`（常人 0.25）；
`sensitivity.valence / magnitude 1.4`：什么都放大。
`expression.anger { aggression 0.90, quitThreshold 0.70 }` 是 §4.9.6 的
「anger→aggression +.9」逐字；`decay.fear 0.80` 是「fear 衰减 .8」逐字。

**用时与表演。**「秒出手」= `tempo.base 200 / dive 800`、`traits.tempo.baseMs 200`；
「他不演」= `theatre 0.10`（情绪都在表情上）；`noise 0.09`。实测均值 287ms（四张卡最快）。

**表情语言。**「表情最多」= `emotes { rate: 0.95, favourites: ['🔥','😭','😂'], cap: 4 }`。

**破绽。**
① 上头后小金花也梭 → **拿真牌等他**（只玩顺金以上、不抢在他前面加价、他梭了就接）：
8000 局净赚 **19.58 ± 2.17k/局**，同一套动作对老油条 8.04 ± 1.42、对常人 12.00 ± 1.55，
差值 **11.54 ± 2.60k/局**（CI 不含 0）。
**但「对老油条不净胜」这条对照没做成** —— 在单挑口径下做不到，见报告的异议第 2 条。
② 对偷池免疫但对价值加注全付 → **真牌加档收口**（只玩前 35% 的牌、一档一档加、
第 2 轮比牌收口不进梭哈、他反加就退）：8000 局对阿凯 **+2.08 ± 1.28k/局**，
对老油条 **−1.13 ± 1.10**、对常人 **−2.32 ± 1.17** —— 完整的正反对照都成立。

## 三、岩石 · 老陈（老实人）

> §4.7.3 原话：只用真牌说话。粗记牌、1 轮前瞻；只在顺金以上加注、豹子才梭哈；
> 面对加注金花以下必弃；比牌只在确信时。破绽：加注 = 亮牌，人人可躲；容易被偷池。
> 情绪：不上头、不记仇；用时随牌力单调（牌好想得久，破绽）；表情🙏为主。

**起手与看牌。**让他掀牌的是「有人开火了 / 这一口开始贵了」，不是「又过了一轮」：
`pressureWeight 0.45`、`costWeight 1.20`，而 `roundWeight 0.50`（常人 1.50 的三分之一）。
实测 r1 72.3% → r2 85.7%：他大多数手牌在第一轮就看完了 —— 「只用真牌说话」的人
必须先知道自己是不是真牌；相邻轮跳变 13.4%，远低于验收上限 55%。

**线路偏好。**卡里**根本没有**「价值加压」和「偷池」两条线 —— 一条线不写进
`persona.lines`，引擎就永远不会走它。这是「只在顺金以上加注」的结构实现：
不是加一个 `if (分位 ≥ 0.97)`，而是**把中等胜率的加压这条路整个拿掉**
（那条线的 `lineFit` 是 `bell(eq, 0.675, 0.13)`，正是岩石不做的那件事）。
「面对加注金花以下必弃」= `弃 1.70`，四张卡里第二高；`跟到底看 0.35` 是最低。
实测**顺金以下加注只占 1.0%**（192 次加注），验收线是 < 5%。

**认知能力。**`rangeFidelity 1`（粗记牌）、`lookahead 1`（1 轮前瞻）、
`readsTiming false`、`classifyOthers 'coarse'`。

**认知偏差。**「只用真牌说话」= `R4 ×0.5`（投进去的钱不替他说话）、`R16 ×0.3`
（对没看的牌没有幻想）；「不上头」= `R5 ×0.3`、`R6 ×0.4`、`R7 ×0.3`；

**比牌习惯。**「只在确信时」= `heads 0.80 / multi 0.88` 抬高 + `blind 0.05`。

**梭哈习惯。**「豹子才梭哈」= `allIn.valueFloor 0.97`（豹子档的分位下界是 0.87）、
`initiate 0.12`。实测主动梭 85 次，牌力均值 **0.916**，顺金以下只占 2.4% ——
常人是 0.758 / 52.8%。

**情绪曲线。**`tilt { trigger 0.85, gain 0.20, recover 2 }`、
`emotion { tiltTrigger 0.30, tiltGain 0.15 }`（不上头）；
`drives.safety 0.75 / greed 0.15`；
`expression.anger.quitThreshold −0.20` 是 §4.9.6 的「anger→foldThreshold −.2（越气越紧）」逐字。

## 四、跟注站 · 小北（看戏的）

## 老王（闷牌王）

> 「不看牌，闷着压，闷着比。看牌是弱者的行为。输了才会看，看了就上头。」

### look —— 看牌习惯
`appetite 0.62 / blindLove 0.88 / pressureWeight 0.10 / costWeight 0.34 / roundWeight 0.95 /
tierWeight 0.20 / allInWeight 0.10`

`blindLove 0.88` 是这张卡的骨架：闷着本身就是他要的东西，不是省钱的手段。
所以别人一开火（`pressureWeight 0.10`）、单价升档（`tierWeight 0.20`）、
有人全下（`allInWeight 0.10`）都基本推不动他去看牌 —— 唯一推得动的是**轮数**
（`roundWeight 0.95`），也就是「闷到实在闷不下去了」。

### lines —— 路线
| 路线 | weight | commit |
|---|---|---|
| 闷压 | 1.60 | 0.66 |
| 偷池 | 1.50 | 0.80 |
| 闷比 | 1.30 | 0.60 |
| 价值加压 | 0.85 | 0.44 |
| 收口 | 0.85 | 0.55 |
| 弃 | 0.66 | 0.50 |
| 跟到底看 | 0.58 | 0.30 |
| 养池 | 0.55 | 0.52 |
| 便宜看戏 | 0.34 | 0.34 |

闷压/闷比排在最前，弃牌线（0.66）压在常人之下 —— 「闷着压、闷着比」和「不肯放手」是同一件事。
偷池 1.50 + commit 0.80：他诈唬起来是真敢加到底的。

### cognition —— 系统 2 工具与系统 1 原型
`rangeFidelity 2 / lookahead 1 / readsTiming true / classifyOthers 'fine' /
s1Prototypes {monster 1.08, strong 1.02, medium 0.99, weak 0.94, blind 1.22}`

他是老手，看得懂人（`fine`）也看得出节奏（`readsTiming`），但不算深（`lookahead 1`）。
`blind 1.22` 是「闷牌感觉上更强」这条自我服务的偏差，正是他敢闷压的心理来源。

### biases —— 偏差
`sunkCost 0.62 / gamblersFallacy 0.14 / lossAversion 0.18 / overconfidence 0.30`
沉没成本是他最大的洞：钱进了池子就拿不回来了。输赢本身他不怕（`lossAversion 0.18`）。

### compare —— 比牌口味
`heads 0.46 / multi 0.62 / blind 0.95 / grudge 0.85 / softness 1`
`blind 0.95`：闷着开比是他的招牌动作。`softness 1` = 会挑软柿子，但不刻意。

### allIn —— 全下口味
`initiate 0.50 / valueFloor 0.72 / bluff 0.22 / accept 0.05 / blindAccept 0.82 /
foldEquityWeight 0.85`
全场诈唬率最高（`bluff 0.22`），并且他愿意闷着接全下（`blindAccept 0.82`）。

### emotion —— 情绪曲线
`tiltTrigger 0.14 / tiltGain 0.70 / decay 0.80 / ease 0.35 / grudge 0.90`
「输了才会看，看了就上头」：门槛低、上得不算猛、但退得慢，而且记仇。

### traits —— 通用人性参数（§4.9.6 原文照抄的偏斜）
`R7 ×1.6`（怒后加压）、`decay.revenge 0.09`（记仇退得慢）、`R16 ×1.9`（自我服务归因）、
`R4 ×1.7`（沉没成本）、`R11 ×0.5`（**不怕大注**）、`baseline.fear 0.05`、
`drives.pride 0.45 / safety 0.28`、`cognition.selfControl 0.66 / needForCognition 0.58 /
narrowFraming 0.50`、`tempo.jitter 0.55`、`tilt {trigger 0.60, gain 0.75, recover 4}`。

### tempo —— 用时
`base 420 / dive 3400 / theatre 0.88 / noise 0.055 / leak 0.05`
`theatre 0.88` + `leak 0.05`：他很爱演，而且演得跟牌力无关 —— 用时几乎读不出信息。

### emotes
`rate 0.62 / favourites ['😱','🤔'] / cap 3`

### leaks —— 破绽

## 破绽利用（增量口径，8000 手对局，95% 置信区间）

猎手 = 一张常人卡 + **一条**固定改写。对照卡是 `常人己`（另一张常人卡）。

**为什么量的是增量而不是绝对成绩**：实测「常人甲什么脚本都不带」对小林每手就已经赢 3.6k
—— 数学型自己弃得太多，对局本身带着落差。拿绝对成绩判定，任何脚本打他都会「净赢」，
量出来的是牌桌经济学，不是破绽。所以一格判定要四段样本：

```
脚本增量      = 靶子·有脚本 − 靶子·无脚本
对照增量      = 常人己·有脚本 − 常人己·无脚本
增量之差      = 脚本增量 − 对照增量      ← 「这个多赚只发生在这张卡身上」
```

四段相互独立，方差相加。**通过标准：脚本增量 > 0 且 95% 区间不含 0，
并且增量之差 > 0 且 95% 区间不含 0。** 8000 手（原来 4000 手）是被这个口径逼上去的：
4000 手时合成区间半宽约 ±6k，比要量的效应还大（同一条脚本 6000 手量到差 6.3k、
12000 手量到 1.4k，全是噪声）。

| **老王**：有闷家就凭牌力升档（s≥0.55），没闷家就见火跟到底 | 老王 | **+28.9k** [21.7k, 36.2k] | −5.8k [−10.2k, −1.5k] | **+34.8k** [26.3k, 43.2k] | ✅ 通过 |

### 一句话总结

- **用时这条线整体是断的**（#1 #2 #4 #7 #8）：`tempo.leak` 在 `shared/` 里
  **一个消费方都没有**（`grep -rn '\.leak' --include='*.ts' shared/` 去掉人物卡目录后 0 命中），
  `tempo.theatre` 有消费方但触发条件是随机数而不是牌力。
  所以四张卡的 `tempo.*` 现在只影响「平均按多久」，不影响「什么时候按得久」——
  「用时破绽」这一期一条都验不了，验收脚本连打都打不了。
- **需要核心改动**的六条里，#11 #12 #13 #14 是同一件事的四个断面：
  **记仇这套机制目前是常人级的、归因还错三分之一**，人物卡在它上面加不了戏。

## 与既有测试的冲突（留给集成）

把 `老王` 路由到手写卡之后，仓库里三条**既有**测试会红。它们全部由老王一张卡引起
（逐张开关路由验证过：只路由小林 → 22 通过 0 失败；只路由老王 → 19 通过 3 失败），
而且都不是老王写错了，是这三条断言原本量的是「六张常人卡自对弈」的桌面统计：

1. `tests/zjh-mind.test.ts` §6.4「闷比占比牌 5–15%」：不路由 13.0%，路由老王后 42.1%。
   基线已经贴在 15% 的上沿，只剩约 32 手闷比的余量；老王是「闷着比」的人，
   一个座位就要贡献几百手闷比。**任何**以闷比为招牌的人物卡都不可能落在这个带里 ——
   这条带子是给常人桌定的，P3 之后要按人物卡分别定带，或者只对常人座位统计。
2. `tests/bots.test.ts`「大牌早比 < 5%」：不路由 4.06%(60/1477)，路由老王后 5.48%(81/1477)。
   拆开看：**看过牌**再早比的 53 → 52（没变），闷着比的 7 → 29（全部增量）。
   这条指标按**实际牌力**统计，但没有排除闷牌 —— 一个没看牌的人不可能「把大牌提前变现」，
   他根本不知道自己拿了豹子。建议指标加 `looked` 过滤。
3. `tests/zjh-mind.test.ts`「看牌不是一条 roundNo >= 2 的门槛」（相邻轮跌幅 ≤ 0.05）：
   不路由 r1 34.5% → r2 81.8% → r3 87.9% → r4 89.5%；路由老王后
   34.5% → 67.6% → **62.4%** → 50.2%。这是辛普森悖论：到第 3 轮还闷着的人几乎只剩老王，
   于是「总体看牌率」被换人换低了，不是谁身上出现了门槛。
   同一条测试里的**按人物卡**统计仍然全部单调。建议改成按人物卡分别判。

B 线没有改这三条测试（任务书禁止改既有测试），也没有为了迁就它们去削老王的人设。
