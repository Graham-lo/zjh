## 原 14 项接线的落点

| 原项 | 当前落点 |
| --- | --- |
| 1 大牌装犹豫、小牌秒跟 | `tempo.ts::shapeThinkTime`，只在已看牌后按真实已知牌力塑形 |
| 2 对手用时进入读牌 | `HandEvent.msSpent` → `range.ts`；只有 `readsTiming` 人物使用 |
| 3 表演被抓后收敛 | `theatreDamp/theatreNow` 同时影响用时表演与偷池评分，随结算衰减恢复 |
| 4 数学型边缘慢 | `tellCurve('edge-slow')` |
| 5 被谁诈过 | `MindState.bluffedBy` 与 R9；键统一为长期身份 |
| 6 下注尺寸透露范围 | 自对弈记录合法加注档位，生成按档位分层的条件似然；稀疏格保留较粗估计 |
| 7 新手弱牌慢 | `tellCurve('weak-slow')` |
| 8 新手强牌秒加 | `snapRaise`，只联动自己发起的加注/梭哈 |
| 9 对子高估 | 原型槽按本桌 `categoryBands(mode)` 对应牌型；不再借用旧 92% 档的分位常数 |
| 10 指向具体人的表情 | 协议、玩家状态和座位 UI 保留 `target`，显示目标昵称 |
| 11 针对时放宽 | R14 按人物 `grudgeGain` 和规律系数缩放通道 |
| 12 更愿意接仇人的梭哈 | 两个系统均读取当前梭哈发起人的稳定记忆键 |
| 13 仇恨持久身份 | `socialKey/socialValue/normalizeSocialKeys`，账户改昵称、换房间仍可对应 |
| 14 比牌淘汰归因 | 结算记录真正比掉此人的对手，避免一律归给最终赢家 |

“有接线”与“达到效果量”分开验收。时间差、弃牌率、针对率、破绽脚本净收益的结果统一收在验收文档，不沿用草稿中的旧数字。

## 自对弈似然与公开归类

运行 `node scripts/zjh-generate-model.ts 2000`。标准档和娱乐增强档分别模拟，每个人物每档 2,000 局，常人作为第九个对照；每 100 局重开独立房间，每第五块仅作留出验证。每手重置筹码，避免破产导致采样桌型改变。模型从空的学习表启动，生成结果不反向影响自身训练。

输出 `shared/zjh/bot/learned-model.json` 与 `docs/zjh/persona-model-validation.json`。模型记录源码 SHA-256、固定种子、每人局数和公开样本数；模拟器暗牌仅作离线似然标签。运行时分类器只读公开动作频率、第一轮已看牌行为和用时，不读名字、账号、机器人标记或暗牌。样本不足及远离训练分布时保留未知；这不等于已经证明能准确识别真人。

动作似然按发牌档、前后轮次、动作、单价档位分层，并记录每个牌力桶的合法行动机会数。先做小样本平滑；精细格不足时读取该人物较粗的动作表，再不足才回到解析先验。闷牌动作永远不用于推断该人的暗牌强弱。

## 跨局状态

公开统计随 `zjh_memory` JSON 存储；R17 保留最近三局增量，让这些观察在累计统计基础上再加一份权重，常人相当于总权重 2 倍。旧档案没有新字段时按未知读取。R25 把展示欲接到既有表情概率，遵守人物频率与每局上限。

通用层仍不导入牌桌代码。牌型、范围、下注尺寸、事件归因和表情目标都由炸金花领域层负责。
