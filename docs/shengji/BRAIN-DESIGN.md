# 升级机器人策略引擎设计（2026-09-03）

> 目标：机器人（同时也是「提示」按钮、超时代打、掉线代打）像一个**会算分、会记牌、会配合、会规划最后一圈**的真人。
> 规则以 `DESIGN.md` §1 为准；抠底倍数按用户口述修正（§0.2）。
> 本文是实现规范：`shared/sj/bot.ts` 的重写以此为准，`SPEC-2026-09-03-select-and-brain.md` §B 是验收清单。
> 覆盖范围：亮主 / 反主 / 加固 / 抄底 / 扣底 / 首出 / 跟牌（四个位置）/ 毙与盖毙 / 垫牌 / 甩牌 / 尾局与抠底 / 结算门槛 / 通关局，
> 每个动作都给出候选、评估要素和"人会怎么做"的场景清单（§9）。

## 0. 先把账算清楚：这游戏到底在比什么

### 0.1 唯一的账本是闲家得分 s

全场 200 分（5=5，10=10，K=10）。结算只看闲家拿到的 s（含抠底、甩牌罚分）：

| s | 结果 | 对闲家的"级差" |
|---|---|---|
| < 0 | 庄家升 4 | −4 |
| 0 | 庄家升 3（大光） | −3 |
| 5–39 | 庄家升 2（小光） | −2 |
| 40–79 | 庄家升 1 | −1 |
| 80–119 | 闲家上台 | 0 |
| 120–159 | 闲家上台升 1 | +1 |
| 160–199 | 闲家上台升 2 | +2 |
| ≥ 200 | 闲家上台升 3 | +3 |

**一分的价值不是常数**：s 在 75 附近时 5 分决定上不上台；s 在 100 附近时 5 分几乎不改变结果。
引擎里所有"值不值"的判断，最后都换算成**闲家得分的期望变化 × 该分数段的边际价值**（§4.1）。

**80 分是分水岭，两边的打法在这条线前后完全不同：**

- **闲家方**：先全力上 80（上台）；过了 80 之后目标不是"守住 80"，而是继续往 120/160/200 冲 —— 每过一档多升一级，
  所以 80 之后仍然要拼分，只是不再需要冒"掉回 80 以下"的险（罚分 −10 是唯一会掉回去的途径，甩牌更要证明）。
- **庄家方**：目标是**空分**：把 s 压到 0（大光 +3）、压到 40 以下（小光 +2）、至少压在 80 以下（守庄 +1）。
  闲家已过 80 后，庄家方的目标变成**别再让他们过 120/160**，每一档都是少升一级。
- 所以同一手牌，我方 s=75 时值得用大主截 5 分，s=100 时同样的 5 分不值一张主。这由 §4.1 的边际价值 m 和 §4.3 的 sign 一起实现，
  不允许写成"闲家过 80 就随便打"的硬编码。
- **通关局**（庄家方处于顶级：五十K 的 K、打通关的 A）：守住即赢整场，庄家方"守 80"权重 ×1.5，闲家方"过 80"同理。

### 0.2 抠底（用户给定，覆盖 DESIGN §1.8 现有写法）

最后一圈闲家赢，底牌分 × 倍数计入 s。倍数看**首出牌型**：单张 ×2、对子 ×4、两连对 ×8、三连对 ×16……
即 `2^(1 + 最长拖拉机的对数)`，上限 64；盖毙不改变倍数。
底牌 8 张，期望 ≈ 15 分（200 × 8/108），对子抠底 60 分、拖拉机抠底 120 分 ——
**抠底是全局最大的一笔账，双方都必须从扣底那一刻就开始规划最后一圈。**

### 0.3 机器人的信息集（不许偷看，但有记牌器）

- 自己的手牌；
- 公开信息：`playedIds`（本局已出的全部牌）、`trick`（本圈已出）、`lastTrick`、`voidGroups`（公开缺门）、
  `dealerSeat`、`kouSeat`、`trump`（含 `declarerId`、明牌）、`levels`、`trickNo`、`defenderPoints`、`handTrickPoints`、
  `penaltyPoints`、`flipped`、各家剩余张数、亮主/抄底历史（谁亮了什么、谁反了谁）；
- `bottom` **只有扣底者本人可读**（是他自己扣的）。

"记牌器"= 从上面这些推出来的一切（§2）。不许读其他三家 `hand`；防偷看测试：重洗他人手牌后决策必须逐位一致。

## 1. 引擎结构

```
shared/sj/brain/
  view.ts        记牌器 + 局面视图（纯函数，从公开状态和我的手牌算）
  infer.ts       持牌推断：某单位在谁手里的概率、稳赢判定、可被毙概率
  value.ts       分值 → 效用（边际价值）、各种"代价"的分值换算
  candidates.ts  首出/跟牌候选生成（完整、去重、带结构标签）
  evaluate.ts    对每个候选算 EV（单位：闲家得分期望变化 × 边际价值）
  declare.ts     亮主 / 反主 / 加固 / 抄底
  kou.ts         扣底 + 抠底计划（closer）
  lead.ts / follow.ts   首出 / 跟牌 = 生成候选 → 评估 → 排序
bot.ts           保持现有导出（botDeclare/botChao/botKou/botPlay/suggest/rankLeads/rankFollows），内部调用 brain
```

`suggest()` 返回 `evaluate` 排好序的候选（最多 5 个），机器人取第 0 个 —— 一个脑子，两个出口。
每个候选带 `why: string[]`（"对家稳赢，垫 10 分"、"留主对子锁最后一圈"），提示面板可以展示，测试断言也用它。

## 2. 记牌器与局面视图（`view.ts`）

```ts
interface BrainView {
  ctx: SjCtx;
  me: number; partner: number; opps: [number, number];
  iAmDealerTeam: boolean;             // seat%2 === dealerSeat%2
  iAmKou: boolean;                    // 我扣的底，bottom 对我可见
  handSize: number;                   // 我还剩几张
  isLastTrick(count: number): boolean;// handSize === count
  matchPoint: boolean;                // 庄家方处于顶级（通关局）

  // ---- 分数账本
  defenderPoints: number;             // 已入账（含罚分）
  pointsOnTable: number;              // 本圈桌上
  unseenPoints: number;               // 场外（他人手里 + 底）还有多少分
  unseenPointCards: { five: number; ten: number; king: number };
  bottomPointsExact: number | null;   // 扣底者才知道
  bottomPointsExpected: number;       // 否则 unseenPoints × 8 / unseenCount；最后一圈时 = unseenPoints（场外只剩底）
  need: { defendersTo80: number; dealerCanStillGive: number };

  // ---- 每门的记牌器
  groups: Record<SjGroup, {
    mine: SjCard[];
    unseen: SjCard[];                 // 场外这门还有哪些牌（含底；扣底者已剔除底）
    unseenCount: number;
    holders: number[];                // 未公开缺门、且可能还持有这门的其他座位
    unseenTop: number;                // 场外最大的 order
    unseenRuns: SjRun[];              // 场外还能凑出的对子/连对（判对子/拖拉机绝张）
    sureMax(unit: SjUnit): boolean;   // 场外没有同类更大 → 绝张
    ledTimes: number;                 // 这门被首出过几次（探路/回牌用）
  }>;
  trumps: { mine: number; unseen: number; perHolder: number; oppsMayHold: boolean; partnerMayHold: boolean;
            topUnseen: SjCard[] /* 场外比我最大主还大的主 */ };

  // ---- 本圈
  trick: { lead: SjShape | null; plays: {seat, cards}[]; leaderSeat; bestSeat; bestIsPartner;
           position: 0|1|2|3; toAct: number[] /* 我之后要出的座位 */ };
}
```

`holders` 规则：座位 x 在门 G 的候选持有者当且仅当 `!voidGroups[x].includes(G)`。
扣底者本人算 unseen 时**把底牌剔除**（场外剩的就是三家手里的）。
最后一圈（handSize === 首出张数）所有人都知道：场外未出的牌 = 底牌，所以 `bottomPointsExpected` 在最后一圈对每个人都是精确值。

## 3. 持牌推断（`infer.ts`）

不做精确概率分布，用"人脑级"近似，便宜（每步 < 20ms）且方向正确。

- **pBeat(seat, G, X)**：seat 持有门 G 中至少一张能盖过单位 X 的牌的概率。
  seat 已知缺 G → 0；否则 `min(1, k / |holders|)`，k = 场外 G 里比 X 大的同类单位数
  （单张按张数、对子按对数、拖拉机按能盖的链数；对子/拖拉机用 `unseenRuns` 判）。
- **pTrump(seat, lead)**：seat 在副牌首出 G 上能毙的概率 = `P(缺 G) × P(手里有足够结构的主)`。
  `P(缺 G)`：公开缺门 = 1；否则按 `unseenCount(G) / |holders|` 估他这门还剩几张：< 1 记 0.6，1–2 记 0.2，≥ 3 记 0.05。
  `P(有主)`：`trumps.unseen / (可能持主的座位数)` 估他手里主的张数 n；单张需 n ≥ 1；对子需 n ≥ 2 再 × 0.5；拖拉机再 × 0.3。
- **secureWin(play)**：对我之后每个对手 pBeat 与 pTrump 都为 0。用于"垫分"这类要绝对把握的动作。
- **pTeamWin(candidate)**：设 best = 我出 candidate 后本圈当前最大的一手。
  best 是我方：`1 − Π_{对手 o ∈ toAct}(1 − max(pBeat(o), pTrump(o)))`；
  best 是对手：对家还没出 → `max(pBeat(partner), pTrump(partner))`，否则 0。
- **对家持主估计**：`partnerTrumps = trumps.unseen × (对家份额)`，份额默认 1/3，若对家亮过主 +0.2，若对家公开缺主 = 0。
- **跟牌结构也是公开信息**（记进 view，和缺门同级）：对子首出而某家用两张单跟 → 他这门**没有对子了**；拖拉机首出而某家只用散对跟 → 他没有同长拖拉机；
  某家毙牌 → 他缺这门且主至少少了那么多张；某家在输的圈里垫出 10/K → 他手里已没有安全的小牌（这门与别门都短）。
  这些让 `unseenRuns`/`pBeat` 对具体座位收紧：对子/拖拉机绝张的判定按座位剔除。
- **同牌先出者大**：`sureMax` 只看**严格更大**的单位；我出 A 时场外另一张 A 盖不过我（相等先出者赢）。对子首出时对手的单张 A 也盖不过。
- **亮主历史也是信息**：亮主/反主/抄底者手里该花色的主至少 1–2 张且大概率长；被反掉的人手里原花色也长（那门对他就是"准副主"，别在那门给他送分）。

## 4. 分值与效用（`value.ts`）

### 4.1 边际价值 m

估最终 s 的中心：`sProj = defenderPoints + (pointsOnTable + unseenPoints) × share`，
`share` = 闲家对剩余分的估计占比：基线 0.5，按主牌控制修正（我方持主 + 估计对家持主 相对 对手 的差，每多 3 张主 ±0.05，夹在 0.2–0.8）。
`m = 1 + 2·exp(−(d/12)²)`，d = sProj 到最近门槛（0/5/40/80/120/160/200）的距离；通关局对 80 这道门槛再 ×1.5。
两队用同一个 m。

**d 不对称**（2026-09-03 裁定，实现见 `value.ts` 的 `PASSED_STRETCH = 1.6`）：闲家分只增不减，已经越过的门槛只剩保值意义，
还没拿到的那道才是要奔的目标。所以对已越过的门槛按 1.6 倍距离计：`d = s ≥ t ? (s − t) × 1.6 : t − s`。
否则 s=85 和 s=115 会拿到同一个 m，而 §9.J5 要求 s=115 更值得拼。

### 4.2 各种"代价"（都是**期望闲家分**量纲，正数对我方有利）

| 项 | 含义 | 估法 |
|---|---|---|
| `trickPts(c)` | 这一圈的分 | 桌上 + 我出的 + 若我方稳赢且对家未出：对家可垫分的期望（unseenPoints/3，上限 20） |
| `tempo` | 赢圈后由我首出的价值 | 我手里安全首出（绝张 / 可喂对家）的个数 × 1.5，上限 4；尾局若我持 closer 再 +2（掌握节奏才能把 closer 留到最后） |
| `trumpSpend(c)` | 花掉主牌的未来代价 | 普通主每张 1.5；顶张主 = 它在抠底计划里的价值（§6.3），不在计划里 3 |
| `winnerSpend(c)` | 花掉副牌绝张 | 该门场外剩余分 / (|holders|+1)，最低 2 |
| `structureBreak(c)` | 拆对子/拖拉机 | 拆对 1，拆拖拉机 3（拖拉机是抠底倍数的本钱） |
| `voidGain(c)` | 垫牌造出/接近缺门 | 垫完剩 0 张 +2、剩 1 张 +1；前提我还有主 |
| `giftRisk(c)` | 带分出去而我方不稳赢 | pts(c) × (1 − pTeamWin) |
| `probeValue(c)` | 探路 / 建立长门 | 0.5 + 0.1 × 该门张数（仅首出小单张） |
| `digPlan(c)` | 对最后一圈的影响 | §6.3 |
| `throwRisk(c)` | 甩牌被管的罚分 | 10 × (1 − 全部单位都是绝张的把握) |

### 4.3 EV

```
EV(c) = sign × [ (2·pTeamWin − 1)·trickPts(c) + pTeamWin·tempo
                 − trumpSpend − winnerSpend − structureBreak + voidGain + probeValue
                 − giftRisk − throwRisk + digPlan ] × m
```

`sign`：闲家方 +1、庄家方 −1（庄家方赢圈 = 那些分不进 s，等价于守住）。

同分打平的次序（人的习惯）：**牌小者先、不带分者先、不动主者先、不拆结构者先**。

## 5. 局前：亮主 / 反主 / 加固 / 抄底 / 扣底

### 5.1 亮主（发牌中即可，`declare.ts`）

**能亮什么**由 `legalDeclarations` 给出；**要不要亮、亮哪个、什么时候亮**由这里决定。

牌力评估（对每个候选主 T，含无主）：
```
strength(T) = 主张数 × 1
            + 大王 × 1.5 + 小王 × 1.2 + 主级牌 × 1.2 + 副级牌 × 0.8
            + 主里对子数 × 1 + 主里拖拉机每条 × 2
            + 副牌 A 张数 × 0.5 + 副牌对 A × 0.5
            − 副牌"两张以内的短门"数 × (−0.3)   // 短门是好事：扣底能造缺门
            − 副牌单张（非 A）数 × 0.2
```
无主的 strength 只数王和级牌 + 副牌里的 A/K 与对子（无主时副牌大牌都是硬通货）。

**亮不亮是一笔收益账，不是达标就亮。** 三种可选动作：现在亮 / 等着反别人 / 等别人亮完再抄底（"虚晃一枪"）。

- **现在亮**的收益：主是我的花色（strength 最高的那门）；第一局还多一个"坐庄 + 拿底"。
  代价：暴露级牌明牌；可能被更高档反掉（我单张亮出去，对手一个对子就反）。
- **等着反**：对手先亮 → 我用更高档反，主还是我的，且多知道了对手长哪门。前提是我手里有对子档（2–7）。
  只有单张（1 档）的人不能指望反别人，达标就该亮。
- **虚晃一枪 / 等着抄底**：我有对子档或对王，不亮、也不反，等别人亮主扣完底再抄：
  主换成我的花色、8 张底到我手里（重扣、造缺门、闲家方还能埋分）、并且已经看到了对手的明牌与扣底节奏。
  第一局抄底视同反主 → **抄底者坐庄**，所以第一局的"等着抄"= 用别人扣过一次的底再扣一次，收益最高。
  风险：无人亮主翻底定主（那时 1 档就能抄，风险不大）；对家先亮了（那就不用抄）；对手在抄底轮先于我抄走（顺序：庄家下家起）。
  规则：`strength(我的最佳主) ≥ 亮主门槛 + 1` 且档位 ≥ 2 → 采用"等"；发牌结束前 5 张仍无人亮 → 自己亮。
- **别人当庄时我要不要亮**（第二局起）：级牌是庄家队的级别，我亮主只是替庄家队选花色。闲家方亮主的唯一收益是"主换成我长的那门"，
  所以看**手里主的数量和质量**：该门 ≥ 9 张、或对王无主且王 + 级牌 ≥ 9 → 亮；否则不亮，让庄家方自己亮或翻底，把抄底的机会留着。
  庄家方亮主收益正常（就是给自己队选主），达标即亮。

**手里有几种亮法时的"钓鱼"（用户口述）**：档位只能从下往上抄（方 < 梅 < 红 < 黑 < 对小王 < 对大王），不能反过来；
不满足条件的人只能跳过。所以持有多档的人可以**先亮低档钓别人抄底，再用高档反抄回来**：
- 收益：最后一个抄底的人拿到的是别人扣过的底（多一次信息）、看到了对方亮的花色（他那门长）、第一局还坐庄。
- 前提一：我的最高档 ≥ 别人可能拿出的任何档。从我手里的级牌/王推场外：我持对大王 → 没人能到 7 档；我持对小王且对大王至少一张在我手 → 没人能到 7；
  我最高只有 ♠ 对 → 场外若还有对小王/对大王的可能就别钓（被 6/7 档反了我抄不回来）。
- 前提二：钓饵本身也得能打——没人上钩我就得用它当主（当前亮主者只能用对王自反成无主），所以 `strength(钓饵) ≥ 门槛`。
- 前提三：别人可能上钩。场外剩余的级牌对子/小王对子越多（由我手里数出），钓到的概率越高；一个人都不可能有对子档就直接亮最高档。
- 钓饵选**最低的可用档**（给对方最多的反抄空间），最终落点是我真正想要的主；用对大王收网的落点必然是无主，所以只有 `strength(无主)` 也过关时才用对大王收网。

**抄底后扣什么**（用户口述）：抄底者一般把**上一个亮主者的花色**扣掉 —— 他那门长，我那门短且打不过，扣光造缺门以后就能毙他的长门。
权衡：若我能抄的那门很短、甚至比我手里"上一个亮主花色"的张数还少，抄了主反而变少，这时要比 `strength(新主)` 与 `strength(旧主对我)`，
差值不到 2 就不抄；抄成无主（对王）不受这条限制，因为无主时各门长短无所谓。

**无人亮主的处理**（用户口述，替换 DESIGN 1.4 的翻底）：发牌全程无人亮 → 再给 **8 秒**；仍无人亮 → **默认无主**，并且**跳过抄底**（谁都不能再抄）。
所以"等着抄"的人要清楚：等到没人亮，就只能在这 8 秒里自己亮，否则无主开打。机器人在 8 秒窗口里按门槛正常亮。

**具体规则**（发牌进行中，每来一张牌重算；只在自己已收到的牌上算）：
- 入场条件（保留现有门槛）：单张级牌亮 → 该花色主 ≥ 7 张；对子亮 → ≥ 8；对王 → 王 + 级牌 ≥ 9。
- 第一局（亮主者坐庄）：亮主 = 抢庄，要求更严 +1；但对家已经亮了就**不反对家**（除非我是对王无主且明显更强 ≥ +4）。
- 第二局起（庄家已定）：庄家方亮主是给自己队选主，闲家方亮主是**给庄家队选主**（级牌是庄家队的级别）——
  闲家方只有在"我这门极长 ≥ 9 或对王"时才亮，否则让庄家方自己亮或翻底。
- **时机**：发到第 12 张之前不亮单张（等对子）；手里已有该级牌对子直接亮对子；
  发牌结束前 5 张，若达标且无人亮，立即亮（窗口只剩 3 秒）。
- **反主**：只反对手，不反对家（同上例外）。反主要求 `strength(新) − strength(当前主对我)` ≥ 3；
  当前主对我很差（该花色 ≤ 3 张）而我有更高档的对子，差值门槛降到 1。
- **加固**：我已亮单张、又拿到同花色第二张级牌 → 一律加固（免费提高档位、告诉对家我这门长）。
- **对王反成无主**：自己亮过的人也能反成无主；只在王 + 级牌 ≥ 9 且副牌 A/K 多时做。

### 5.2 抄底（`declare.ts`，被轮询到时决策）

抄底 = 亮一手更高档的牌，拿 8 张底重扣，主换成我的花色。它对两队意义不同：

- **庄家方抄底**：主换成自己更好的花色 + 再拿一次底（可以把对家扣得不好的底重扣）。条件：`strength(新主) − strength(当前主) ≥ 2`，
  或当前主是对手亮的、且我这花色 ≥ 8 张。
- **闲家方抄底**：主换成对手不熟的花色 + **底牌落到闲家手里**。要点：底里的分最后一圈由闲家抠，闲家扣底时**可以故意埋分**
  （只要我方 closer 稳）。条件：`strength(新主) ≥ 9`；若我有对大王/对小王（无主）并且副牌 A 多，门槛降到 8。
- 每次抄底都把明牌摆出去（暴露 1–2 张），并且 33 选 8 需要更多信息给对手，所以**边际收益 < 2 时不抄**。
- 轮到当前亮主者本人只能用对王反无主：只有王 + 级牌 ≥ 9 才做。
- 抄底得到的 8 张底是未知的：期望 +1.2 分主牌、+15 分分牌，期望值不进 strength，只作为"拿底的价值 = 可以造 2 个缺门"的固定 +1.5。

### 5.3 扣底（`kou.ts`，33 选 8）

给 33 张每张打分，**扣分数最低的 8 张**。尺子（越低越先扣）：

| 项 | 分 |
|---|---|
| 主牌 | +10000（绝不扣主；主 ≥ 15 张时最小的 2 张主降到 +600，允许扣） |
| K / 10 | +3000（被抠翻倍就是灾难） |
| 5 | +1500（真要埋分宁埋 5） |
| 对子成员 / 拖拉机成员 | +500 / +900 |
| 副牌 A | +400；该门场外 ≤ 3 张的准绝张 +300 |
| 同门张数 n ≤ 2（能一把扣干净造缺门） | −300 每张 |
| n = 3 且没有 A/对子 | −120 |
| 门越长 | + n × 20（长门以后能立绝张，别拆） |
| 我亮出的明牌 | +800（扣了等于把底牌告诉全场） |

扣底后固定进行：`closer` 规划（§6.3）与 `bottomPointsExact` 记账。

**闲家方抄底后扣底（故意埋分）**：若我持 closer（主里对场外绝对是绝张的对子/拖拉机）且 `P(最后一圈我方能赢) ≥ 0.8`，
分牌的扣分改为：K/10 → −800、5 → −400（主动埋分，抠底 ×4/×8）；否则按上表。
庄家方永远按上表（庄家方埋分只会送给对手抠）。

## 6. 出牌阶段

### 6.1 首出（`lead.ts`）

候选：每门的所有单张、对子、拖拉机 + 甩牌候选（同门多个单位、每个单位对场外都是绝张，或三家都已公开缺这门）。
甩牌失败罚 10 分 + 被迫出小，所以只提可证明的甩牌；`throwRisk` 压住存疑的。

评估要素（全走 §4.3，这里说明首出时怎么取）：

1. **绝张兑现**：pTeamWin≈1；trickPts = 我出的分 + 对家可垫分期望。副牌绝张若对手已缺门且场外有主 → pTrump 把它压下去，它就不是绝张了 —— 这时先抽主再兑现。
2. **喂对家**：对家公开缺 G、对手未缺 G、对家估计有主 → 出 G 的**分牌**（10/K），pTeamWin 由 pTrump(partner) 提供。闲家方中盘最赚的一手；评估自然浮上来，不特判。
3. **抽主**：出主时 tempo 项加 `drawValue`：若 `oppsMayHold` 且我方（我 + 估计对家）持主多于对手 →
   `drawValue = 1.5 × 我手里"抽干后能兑现"的副牌绝张个数`；庄家方 + `bottomPointsExact > 0 ? 3 : 0`（守底）；
   任一方若对手很可能持有 closer（场外主顶张不在我方且对手未缺主）+ `digValue × 0.3`（抽主 = 拆对方的抠底）。
   两个对手都公开缺主 → drawValue = 0，停止抽主。有顶张主先出顶张（砸出对手的主），否则出小对子。
   **不抽主的情况**：我方主少于对手估计、或我手里没有等着兑现的副牌绝张、或对家明显持主多（抽主只会抽干对家）。
4. **探路**：长门小单张（不带分、非绝张）→ probeValue；输了不心疼；对手已缺该门且有主时 pTeamWin 低但 giftRisk 0，仍是"垫圈"的合理选择。
   优先探**对家可能长**的门（对家亮过/被反掉的花色）、避开**对手亮过**的门（那门对手长且大）。
5. **回牌**：对家首出过的门（`ledTimes > 0`、对家未缺）是对家想要的门 → 同等 EV 下优先回那门；对家缺门的门则是喂毙门（第 2 条）。
6. **拿到首出但没有好牌**：出最短副牌门的最小单张（造缺门 + 探路），绝不出带分的单张、绝不拆对子。
7. **尾局**（剩 ≤ 3 圈或场外张数 ≤ 12）：`holders/unseen` 当确定信息用；对每个候选做一步展望：出完它我下一圈还能不能保住 closer（§6.3）。
8. **最后一圈**：候选的 trickPts 直接加 `bottomPts × multiplier(候选牌型)`（闲家方）或减（庄家方）；拖拉机抠底自然排第一。
   庄家方最后一圈：能赢就出最大牌型赢（不让抠）；不能赢就出**最小牌型**（单张）—— 倍数只看首出，单张出去被闲家毙只是 ×2。

### 6.2 跟牌（`follow.ts`）

候选：单张/对子/同长拖拉机首出 → 全部合法跟法（现有）；甩牌/混合首出 → 结构化枚举：
必出的每条拖拉机取 {最小, 最大}，必出的每个对子取 {最小, 最大, 带分}，填充位取 {最小不带分, 带分, 最大}，笛卡尔积去重后 ≥ 8 个；
缺门时另加：最小能毙、最大毙、主对子毙（首出含对子时）、垫牌集合 {最短副牌门最小不带分、带分（垫分用）、拆对最小}。

按**位置**说明各要素怎么取（position = 我是本圈第几家）：

**第二家（position 1）**
- 桌上无分、对家未出：能赢的候选 trickPts≈0 + tempo，减 winnerSpend ≥ 2 → 通常输给"跟最小"（EV≈0）。这就是**二家小**。
  例外：我这张是绝张（winnerSpend 低）且 tempo 高；或首出带分（10/K）→ 值得截。
- 首出带分且我能稳赢 → 赢；不能稳赢 → 跟最小，把机会留给三家。
- 缺门：桌上有分 → 最小能毙；桌上无分 → 不毙，垫最短门造缺（voidGain）。对手首出带 10/K 且我缺门 → 毙（pTeamWin × pts 远大于 1.5）。

**第三家（position 2，对家已出）**
- 对家稳赢（secureWin 对第四家成立）→ **垫分**（trickPts 最大的候选）。对家领先但不稳 → giftRisk 压住带分候选，跟最小不带分。
- 对家没赢、我能赢 → 最小能赢；对家没赢、我不能赢 → 跟最小不带分（不送分）。
- **绝不盖自家**：我盖过对家的候选多付 trumpSpend/winnerSpend，EV 必低；例外：对家不稳我能稳（pTeamWin 0.4 → 1），盖是对的。
- 缺门、对家在赢且稳 → 垫分（不毙自家）；对家不稳、桌上有分 → 最小能毙护分。

**第四家（position 3，末家）**
- 一切确定：pTeamWin 是 0/1。赢就赢最小、输就垫最小不带分、对家赢就垫最多的分。
- 对手已毙、桌上有分：盖毙当且仅当 桌上分 + 我出的分 > 我要花的主的代价（顶张主还要算 digPlan）。
- 对家已毙在赢、我也缺门：垫分给对家，不盖。

**通用**
- **该毙就毙、不该毙不毙**：缺门 + 桌上有分或首出带分 → 最小能毙；桌上无分 → 不毙，垫最短门。
- **盖毙要算账**：对手毙了，桌上分 ≥ 10 才考虑盖；用最小能盖的主；对家还没出且对家可能有更大主 → 让对家盖（不盖自家的前提也适用）。
- **垫牌造缺门**：压不过时候选 = 各副牌门最小不带分，voidGain 让最短门胜出；绝不垫主、绝不垫分（除非对家稳赢）。
- **庄家方守分**：对手会赢的圈，带分候选 giftRisk 全额 → 排最后；有分的圈能截就截。
- **对甩牌的跟法**：必须跟的结构里，对家赢就填分、对手赢就填最小；对甩牌缺门 → 主里有对应结构才能毙（`validateFollow`），否则垫最小。
- **主牌首出（对手抽主）**：跟最小主；有对手大主未出且我持 closer → closer 成员绝不跟出去（digPlan 负）；对家在赢 → 垫小分主？不：分主（主 5/10/K）只在对家稳赢时跟出。
- **主牌首出（对家抽主）**：对家出顶张主 → 跟最小主；对家出小主探主 → 我有大主可以接管（我方赢圈 + 继续抽）。

### 6.3 抠底计划（`digPlan`，双方都有）

- `closer` = 我手里对场外绝张的**主牌单位**里倍数最高者（拖拉机 > 对子 > 单张）；没有主绝张 → 看"准 closer"：
  `trumps.topUnseen.length ≤ 对手估计主张数 / 3` 时，视为抽干后能成的 closer。
- `digValue = bottomPts × multiplier(closer)`；bottomPts 用 exact（扣底者）或 expected。闲家方是收益，庄家方是要守的损失。
- 任何**动用 closer 成员**的候选，在最后一圈之前 `digPlan = −digValue × P(最后一圈还能靠它赢)` —— 自动实现"尾局留大主"。
- **保 closer 的节奏**：我持 closer 时，尾局要么保持首出权，要么保证最后一圈轮到我方首出（最后一圈由倒数第二圈赢家首出）。
  倒数第二圈：闲家方 = 用次大牌赢下来拿首出（tempo +2），或让对家赢；庄家方 = 同样争倒数第二圈的首出权，然后最后一圈出大牌型堵抠。
- **庄家方**：知道底里有多少分。底里 0 分 → 最后一圈不需要防（digPlan = 0，尾局可以放开打分）；底里 ≥ 10 分 → 必须持有或抽出对手的 closer。
  庄家的对家不知道底分，用 expected；庄家本人若发现底分为 0 且自己有大主，中盘就可以把大主拿出来抽主/收分（不需要留）。
- **最后一圈**：闲家方出倍数最高的能赢牌型；能赢的拖拉机 > 能赢的对子 > 能赢的单张；对家（非首出）在能毙时毙下来也算闲家赢，但倍数看首出。

### 6.4 甩牌（`lead.ts` 内）

- 只甩**可证明**的：每个单位对场外都是绝张（用 `unseenRuns`），或三家都公开缺这门。
- 有一个单位不是绝张 → 拆开出：先出绝张单位，剩的下圈再看。
- 甩牌带分 = 一次收多分（trickPts 高），且把该门清空造缺门；尾局对家缺门时甩牌可能被对家毙（无所谓，仍是我方赢）。
- 最后一圈甩牌：倍数按甩牌里最大牌型 —— 含拖拉机就 ×8/×16，所以最后一圈能甩就甩（只要可证明）。

### 6.5 尾局精算（剩 ≤ 3 圈）

- 场外牌少，`unseen` 几乎就是三家手牌 + 底；对每个候选枚举"对手最坏持牌"做一步 minimax（不超过 3 圈深度、候选 ≤ 8，控制在 20ms 内）。
- 最后一圈之前的每一圈都要回答两个问题：我方谁拿最后一圈首出？对手还有没有比我 closer 大的主？

### 9.B 抄底

- B1 庄家方对家扣完，我 ♠ 对级牌 + ♠ 9 张，当前主 ♥ 我只有 3 张 → 抄。
- B2 庄家方，当前主是对家亮的、我这门只多 1 张 → 不抄（边际 < 2）。
- B3 闲家方，对大王 + 王级牌 9 张、副牌 3 个 A → 抄成无主，扣底时埋 K/10。
- B4 闲家方，♦ 对级牌 ♦ 8 张，但没有主绝张 → 不抄（暴露明牌 + 底牌没法安全埋分，收益不够）。
- B5 我是当前亮主者被轮询 → 仅对王反无主且达标才做，否则"不抄"。
- B6 抄成 ♠ 后扣底：把上一个亮主者的 ♦ 门优先扣光（造缺门毙他的长门），分牌/主/对子仍按 §5.3 保护。
- B7 无人亮主默认无主的局 → 没有抄底阶段，botChao 不会被调用；机器人扣底策略按无主打分（副牌 A/K 权重更高）。

### 9.C 扣底

- C1 33 张：♦ 只有 2 张小牌、♣ 3 张小牌、其余长 → 扣 ♦2 张 + ♣3 张 + 3 张最长副门的最小非分牌，造两个缺门。
- C2 手里 10/K 必须留，实在不够扣才埋 5。
- C3 不扣主；主 ≥ 15 张时可以扣最小 2 张主。
- C4 不拆对子/拖拉机；副牌 A 不扣。
- C5 亮出的明牌不扣。
- C6 闲家方抄底 + 持主对拖拉机绝张 → 埋 K、10 到底里（主动抠底）。
- C7 扣完后 `bottomPointsExact` 入账，closer 计划立即生成。

### 9.D 首出

- D1 手里 ♠A 对（绝张）、对手未缺 ♠ → 出对 A 收分。
