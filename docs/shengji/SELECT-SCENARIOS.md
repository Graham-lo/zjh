# 智能选牌场景清单（2026-09-03）

配套 `SPEC-2026-09-03-select-and-brain.md` §A。原则：**选牌不动牌、系统选的永远能放下、只有规则只剩一条路时才替用户补齐、其余一律交给用户。**
每条至少一个测试（`tests/sj-complete.test.ts` / 组件测试）或浏览器验收项。

## 1. 首出时（没有首出牌型，只有甩牌合法性由服务端裁决）
- S1 点一张牌 → 只选这一张，邻牌不动、不浮起。再点取消。
- S2 点对子中的一张 → 只选一张；双击（或再点另一张）才成对。不自动扩成对子。
- S3 点拖拉机中的一张 → 只选一张；不自动扩成拖拉机。
- S4 按住从左到右滑过 5 张 → 5 张全选；滑回去取消经过的（锚点初始态决定模式）。触屏同理。
- S5 「提示」→ 系统填入一手；再点其中任何一张可以放下；点「提示」再按循环下一候选；出牌按钮只在 `checkPlay` 合法时亮。
- S6 用户手动选了跨门的牌（♠A + ♥K）→ 不合法，按钮灰，提示原因"首出只能同一门"；不替用户改。
- S7 用户选了同门 A + A + K（可能甩）→ 允许出，由服务端裁决甩牌；界面提示"甩牌，若被管上罚 10 分"。

## 2. 跟牌（有首出）
- F1 首出单张，我有该门 → 点任何该门牌即合法；点别门牌 → 不合法，提示"有 ♠ 必须跟 ♠"，不替用户改。
- F2 首出对子，我有该门对子 → 点对子中一张：`forcedCompletion` 若此时合法出法只剩这一对，自动补齐另一张（可放下）；若有多对可选（多种补法）→ 不补，等用户。
- F3 首出对子，我该门只有 2 张单张 → 点一张后补齐唯一另一张（只剩一条路）。
- F4 首出对子，我该门 ≥ 3 张单张无对 → 点一张后不补（有多种填法），按钮在选满 2 张后亮。
- F5 首出拖拉机，我有唯一同长拖拉机 → 点其中一张补齐整条；有多条候选 → 只选一张。
- F6 首出拖拉机，我该门有对子但不成拖拉机 → 点对子中一张补齐该对（对子槽必须用对子填）时仅当补法唯一；否则等用户。
- F7 首出 n 张，我该门张数正好 n → 点任何一张补齐全部（唯一解）。
- F8 首出 n 张，我该门张数 < n → 点该门任一张补齐该门全部（必须全出），剩余张数由用户任选（不补）。
- F9 缺门，选主牌 → 允许混选主 + 副（垫牌），不补；若选的主牌数 = n 且结构覆盖 → 提示"毙"。
- F10 缺门，点一张主 → 不自动扩成"毙"的整手；只有当我主牌数正好 n 或结构唯一时才补。
- F11 甩牌首出（如对 + 单）→ 我有该门对子 → 点对子中一张时对子槽唯一则补齐，否则等用户；填充槽绝不自动填。
- F12 用户选择违反结构（有对子却出两张单）→ 按钮灰，提示"有对子必须出对子"，高亮哪些是对子；不替用户改。
- F13 唯一合法解（`legalFollows` 只有 1 个）→ 轮到我时预选并标注"唯一出法"，用户仍可点掉再点回，按钮亮。
- F14 用户先选了 2 张，再点「提示」→ 提示替换整个选择为候选（用户主动要求）。
- F15 已选牌与提示候选不兼容 → `hinted` 标记不显示（选择非空时不画 hint）。

## 3. 视觉与手感
- V1 选中只有金色描边 + 顶部 1px 高亮条，无 translateY，邻牌不遮不动。
- V2 命中区域几何永不变（3 层 DOM 规则）。
- V3 桌面 1440×900、手机 390×844 都能选到被邻牌压住的那张（点其可见左条）。
- V4 滑选中经过的牌立即反馈（描边），松手才提交。
- V5 出牌后选择清空；回合切换（`turnKey`）时清空非用户手选的预选。

## 4. 扣底（33 选 8）
- K1 点选 8 张后按钮亮；超过 8 张不允许（第 9 张点不上并提示）。
- K2 「提示」给出机器人扣法，可逐张放下换别的。
- K3 滑选可用。

## 5. 亮主 / 抄底条
- D1 只显示 `legalDeclarations` 里合法的按钮；不合法的不显示而不是灰掉。
- D2 发牌中亮主按钮只在该牌已飞到手里后出现。
